# ♠ PokerCircle — покер с друзьями

Свой сайт техасского холдема: регистрация по номеру телефона, личный кабинет с балансом игровых фишек (без денег), столы и турниры, дилер Алиса с голосом и анимацией, всё на русском.

## Хостинг (Render, бесплатно)
Репозиторий содержит `render.yaml` — на render.com: **New → Blueprint →** выбрать этот репозиторий → **Apply**. Через пару минут сайт доступен по постоянной ссылке `https://pokercircle-….onrender.com`.

На бесплатном плане сервер засыпает после 15 минут без игроков — первый заход после этого ~1 минуту. Профили игроков восстанавливаются автоматически из копии на их устройствах.

## Запуск на своём компьютере (Windows)
Двойной клик по `ЗАПУСК ИГРЫ.bat` (Node.js скачается сам). Для игры через интернет автоматически создаётся ссылка Cloudflare.

## Что внутри
- Все правила холдема: блайнды, анте, баттон, 4 круга торговли, минимальный рейз, сайд-поты, делёж банка, таймер хода, пауза
- Рост блайндов настраивается для любого стола: каждые N раздач или N минут
- Кабинет: баланс, бонус каждые 4 часа, история раздач с картами, статистика, рейтинг
- Дилер Алиса: анимация рук при раздаче, озвучка лучшим голосом устройства
- Устанавливается на телефон как приложение (иконка на главном экране)

Файлы: `server.js` (сервер и логика), `poker.js` (комбинации), `ws.js` (WebSocket), `public/` (сайт).
